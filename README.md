# PulseCare Portal

This project was created for **CSI-3150: Web and Mobile Systems** as part of Assignment 2B.

The purpose of this assignment is to build a client-side clinical intake portal using Vanilla JavaScript. The application allows users to record patient vital signs, evaluate triage status, persist records in browser storage, and dynamically manage intake records without reloading the page.

## Project Goals

This project focuses on practicing:

- JavaScript (ES6+)
- DOM manipulation
- Event handling
- HTML5 form validation
- Browser `localStorage`
- Dynamic content rendering
- Client-side state management
- Immediate user feedback
- Error prevention and input constraints

## Technical Requirements

The project is built using:

- HTML5
- CSS3
- JavaScript (ES6+)
- Browser `localStorage` API
